# Changelog

## [1.0.1] - 2026-09-11

### Виправлено
- 🐛 **Критична помилка**: Виправлено проблему з читанням другого вводу користувача. `BufferedReader` тепер створюється один раз для всіх операцій читання і закривається в `finally` блоці.

### Додано
- ✨ Система логування (SLF4J + Logback)
  - Логування в консоль (рівень INFO)
  - Логування у файли з ротацією (рівень DEBUG)
  - Зберігання логів протягом 30 днів
  
- ✨ Кастомні винятки для кращої обробки помилок:
  - `DataProcessingException` - помилки обробки даних
  - `InvalidInputException` - некоректний ввід користувача
  - `FileOperationException` - помилки роботи з файлами

- ✨ Клас `Constants` для централізації всіх константних значень
  - Назви листів Excel
  - Індекси стовпців та рядків
  - Позиції для різних категорій
  - Формати дат

- ✨ Валідація всіх вхідних даних:
  - Перевірка діапазону днів (1-31)
  - Валідація діапазону дат (початок <= кінець)
  - Перевірка існування та доступності файлів
  - Валідація формату даних

- ✨ Детальна документація:
  - JavaDoc для всіх публічних методів
  - README.md з повною інструкцією
  - Приклади використання

- 🔧 **ReferenceDataLoader.java**:
